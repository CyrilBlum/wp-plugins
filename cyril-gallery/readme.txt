Create responsive, accessible photography galleries using the WordPress Media Library.

== Description ==

Blum Gallery adds the [blum_gallery] shortcode and a Gallery Images panel to pages. Choose images from the Media Library, reorder them, add captions and categories, and display them with responsive filters and an accessible lightbox.

== Usage ==

1. Add `[blum_gallery]` to any page.
2. Use the Gallery Images panel to choose and order images.
3. Publish or update the page.
